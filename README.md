HR Analytics Project | Microsoft Excel

1. Project Overview

This project uses Microsoft Excel to analyze employee data and explore workforce trends that can support data-driven Human Resources decision-making.

2. Dataset Overview

The dataset contains 300 employee records and 13 variables covering employee demographics, department, education, work experience, salary, job satisfaction, performance, overtime, absenteeism, training hours, and employee attrition.

3. Data Source

This project uses a synthetic employee dataset created for educational and portfolio purposes. The data does not represent actual employees or a real organization’s workforce.

4. Key Areas of Analysis

* Employee demographics and workforce distribution
* Salary analysis across departments
* Job satisfaction and performance ratings
* Employee attrition analysis
* Overtime and absenteeism patterns
* Training hours and years of experience

5. Tools & Skills

* Microsoft Excel
* Data Analysis
* Data Visualization
* HR Analytics
* Workforce Analytics

6. Project Objective

The objective is to demonstrate how Microsoft Excel can be used to explore workforce data and support HR reporting and organizational decision-making.

7. Future Development

Future projects will expand this analysis using Power BI and SQL.
